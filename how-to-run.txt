============================================================================
HOW TO RUN: TLS/PKI Certificate Diagnosis Expert System
============================================================================

Prerequisites:
--------------
FuzzyCLIPS

Running a Test Case:
--------------------
The system includes several pre-defined test cases in the 'cases/' folder.
To run a specific scenario (e.g., Expired Certificate):

1. Load the system by running:
   (batch* "run.clp")
   This will load the factbase, rulebase

2.Load the test case:
   (batch* "cases/case_expired_cert.clp")

3. Execute the diagnosis:
   (run-diagnosis)

4. (Optional) To see the logic used by the system:
   (show-reasoning)

Available Test Cases:
---------------------
- (batch "cases/case_expired_cert.clp")      : Tests expiration logic.
- (batch "cases/case_hostname_mismatch.clp") : Tests domain identity logic.
- (batch "cases/case_chain_incomplete.clp")   : Tests intermediate CA logic.
- (batch "cases/case_missing_sni.clp")       : Tests SNI configuration logic.
- (batch "cases/case_d2_probabilistic_fuzzy.clp")       : Tests probabilistic reasoning and fuzzy logic.

Case D2 Probabilistic Fuzzy:
----------------------------
- This test case tests how well the system handles uncertain/incomplete information:
   - Certainity Factors: Not everything is 100% certain -> Self-signed certs are risky (CF: 0.95), but okay internally (CF: 0.7)
   - Fuzzy Logic: Boundaries are blurry -> Is "10 days to expiry" critical or just risky?
   - Combined Evidence: Multiple clues strengthen/weaken diagnosis -> Weak protocol + weak cipher = obsolete system (CF: 0.95)

Interactive Mode:
-----------------
To manually enter certificate and environment data and get a diagnosis:

1. Run the interactive command:
   (collect-and-run)

2. Follow the prompts to enter error codes, hostnames, and certificate details.

File Structure:
---------------
- run.clp       : Main entry point; loads all other components.
- factbase.clp  : Defines data structures (templates) for the domain.
- rulebase.clp  : Contains the diagnostic rules and logic.
- ui.clp        : Contains functions for user display and input.
- cases/        : Folder containing batch files for automated testing.
